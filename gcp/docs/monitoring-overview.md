## コンポーネント一覧

| コンポーネント           | 説明                       | コスト                         |
| ------------------------ | -------------------------- | ------------------------------ |
| **Cloud Monitoring**     | メトリクス収集・アラート   | 無料（基本メトリクス）         |
| **Alert Policies**       | エラー率・遅延アラート     | 無料                           |
| **Notification Channel** | Email 通知                 | 無料                           |
| **Cloud Logging**        | ログ収集・除外フィルター   | 無料（50GiB/月、30 日保持）    |
| **Cloud Trace**          | 分散トレーシング           | 無料（Cloud Run 自動トレース） |
| **Cloud Profiler**       | CPU/メモリプロファイリング | 完全無料                       |

## Terraform モジュール構成

```
terraform/modules/
├── monitoring/          # アラート・通知設定
│   ├── main.tf          # 通知チャンネル、アラートポリシー
│   ├── variables.tf     # 閾値、メール等の変数
│   ├── outputs.tf       # チャンネルID、ポリシーID
│   └── versions.tf
│
└── logging/             # ログ除外フィルター
    ├── main.tf          # 除外フィルター定義
    ├── variables.tf     # 除外制御フラグ
    ├── outputs.tf       # フィルター名、状態
    └── versions.tf
```
