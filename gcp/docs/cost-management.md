# コスト管理ガイド

GCP の利用料金、特にお金がかかっている「具体的なサービス（SKU）」を確認する手順を説明します。
不明瞭なコストが発生した場合、この手順で原因を特定してください。

---

## 詳細コスト（SKU 別）の確認手順

GCP コンソールの「お支払い (Billing)」レポート機能を使用します。

1. **レポート画面へのアクセス**

   - [GCP Console お支払い > レポート](https://console.cloud.google.com/billing) にアクセスします。
   - 複数の請求先アカウントがある場合は、対象のアカウントを選択します。

2. **フィルタとグループ化の設定**（ここが重要）

   - 右側の設定パネルで以下を選択します：
     - **期間 (Time range)**: 「今月 (Current month)」または任意の期間
     - **グループ化 (Group by)**: 「**SKU**」を選択

3. **内訳の確認**
   - グラフの下にある表を確認します。
   - 「費用 (Cost)」の降順で並べ替えると、高額な項目が上に来ます。

### 主な高コスト SKU の例

| SKU 名                                  | 説明                              | 対策例                         |
| --------------------------------------- | --------------------------------- | ------------------------------ |
| **Cloud NAT IP Usage**                  | Cloud NAT に割り当てられた静的 IP | NAT が不要なら削除             |
| **Cloud NAT Gateway uptime**            | Cloud NAT ゲートウェイの稼働時間  | NAT が不要なら削除             |
| **Static IP Charge**                    | 未使用の静的 IP アドレス          | IP を解放する                  |
| **Cloud Run Network Data Transfer Out** | 外部へのデータ通信量              | 画像サイズ最適化、CDN 利用     |
| **Cloud SQL - Enterprise Edition...**   | DB インスタンス稼働費             | インスタンス停止、サイズダウン |

---

## 予算アラートの設定

予期せぬ高額請求を防ぐため、予算アラートの設定を推奨します。

1. [お支払い > 予算とアラート](https://console.cloud.google.com/billing/budgets) に移動
2. プロジェクト全体の月額予算を設定 (例: 1,000 円)
3. 予算の 50%, 90%, 100% に達した際にメール通知を受け取るよう設定
